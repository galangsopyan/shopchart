# Shopcart — Next.js App Router

Implemented from the supplied Shopcart UI references.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- `/` — Home
- `/shop` — Headphones/product listing
- `/product/airpods-max` — Product detail
- `/checkout` — Checkout
- `/checkout/success` — Order accepted modal/page

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React

The supplied screenshots were used as the visual reference. Product imagery is loaded from Unsplash so the project runs without requiring a separate asset pipeline.
